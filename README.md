# QPay QRIS Prototype

Prototype web app pembayaran QRIS:
Home -> Scan QRIS -> Nominal -> Konfirmasi -> Berhasil -> Riwayat.

## Menjalankan
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan `index.html` dengan Live Server.
4. Izinkan kamera jika ingin mencoba scanner.
5. Jika kamera tidak tersedia, tekan "Gunakan QR Demo".

Catatan: ini hanya prototype. Belum terhubung ke rekening/payment gateway dan tidak memindahkan uang sungguhan.
